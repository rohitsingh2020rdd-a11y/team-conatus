# Personal Portfolio Website

A responsive personal portfolio website built using HTML and CSS.
# live Demo
[View live website]( https://rohitsingh2020rdd-a11y.github.io/team-conatus/)

## Features
- About Me section
- Education section
- Skills section
- Projects section
- Contact section
- Flexbox for layout
- Position property for element placement
- Box-shadow for styling
- Hover effects for better user interaction
- Clean and responsive design

## Technologies Used
- HTML5
- CSS3

## Purpose
This project was created to practice and demonstrate my frontend web development skills using HTML and CSS.
